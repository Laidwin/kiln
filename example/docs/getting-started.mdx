Kiln needs **Docker** and nothing else: no Node, no npm, no Python packages. This guide adds documentation to an existing project, previews it locally and builds the static site.

## Project layout

Kiln only looks at two things at the root of your project: a `docs/` folder and a `docs.yml` file. The rest of the repo is yours.

## Create your docs

<Steps>

1. **Describe the site** in `docs.yml`. Only `title` is required:

   ```yaml title="docs.yml"
   title: My project
   description: What my project does, in one sentence.
   ```

2. **Write a first page** in `docs/index.md`:

   ```md title="docs/index.md"
   ---
   title: Welcome
   description: The home page of my documentation.
   ---

   Hello from **Kiln**!
   ```

3. **Preview it** with live reload on [localhost:4321](http://localhost:4321):

   ```sh
   docker run --rm -p 4321:4321 -v "$PWD":/project ghcr.io/laidwin/kiln serve
   ```

   Every change to a Markdown file reloads the page. Changes to `docs.yml` or new folders update the navigation too.

4. **Build the static site** into `site/`:

   ```sh
   docker run --rm -v "$PWD":/project ghcr.io/laidwin/kiln build
   ```

</Steps>

:::tip[Add site/ to .gitignore]
The build output is regenerated on every run and does not belong in version control.
:::

:::note[Windows]
In PowerShell, replace `"$PWD"` with `"${PWD}"`. File watching uses polling, so live reload works with folders mounted from Windows and macOS hosts.
:::
