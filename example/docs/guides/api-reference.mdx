Kiln does not generate API references itself: that would require every language's SDK in the image. Instead, generate the HTML with your usual tool into an `api/` folder at the project root. Kiln then:

- publishes it untouched under `/api/`;
- adds an **API reference** link at the bottom of the sidebar;
- serves it in `kiln serve` as well, so links can be checked locally.

## Generate the reference

<Tabs syncKey="lang">
	<TabItem label="Python" icon="seti:python">
		```sh
		sphinx-build -b html docs-api/ api/
		# or: pdoc my_package -o api/
		```
	</TabItem>
	<TabItem label="Java" icon="seti:java">
		```sh
		mvn javadoc:javadoc
		cp -r target/reports/apidocs api
		```
	</TabItem>
	<TabItem label="C#" icon="seti:c-sharp">
		```sh
		docfx metadata && docfx build -o api
		```
	</TabItem>
</Tabs>

Any static HTML works: rustdoc, TypeDoc, godoc, Doxygen… The only requirement is an `index.html` at the root of `api/`.

:::tip[In CI]
Generate the reference in a job step before the Kiln build, and it will be published with the rest of the site. See [Publishing](/guides/publishing/).
:::

:::note
Pages under `/api/` are not indexed by the site search, which keeps results focused on your guides.
:::
