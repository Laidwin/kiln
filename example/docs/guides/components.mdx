import { Aside, Badge, Card, CardGrid, FileTree, LinkButton, LinkCard, Steps, Tabs, TabItem } from '@astrojs/starlight/components';

Asides work in any Markdown file. The other components need an `.mdx` page and an `import` line at the top:

```mdx
import { Tabs, TabItem } from '@astrojs/starlight/components';
```

## Asides

:::note
A **note** adds complementary information, useful but not essential.
:::

:::tip[Good to know]
A **tip** helps readers get more out of your project. The title can be customized.
:::

:::caution
A **caution** flags surprising behavior or a common pitfall.
:::

:::danger
A **danger** warns about a destructive or irreversible action, such as `rm -rf site/`.
:::

<Aside type="note" title="Also as a component">
Asides are also available as the `<Aside>` component in MDX files.
</Aside>

## Steps

<Steps>

1. Create a `docs.yml` file at the project root.
2. Write your pages in `docs/`.
3. Run `kiln serve` through Docker.

</Steps>

## Collapsible details

<details>
<summary>Why does Kiln run in a container?</summary>

So that no project needs Node, npm or a pinned Astro version. The container ships the exact toolchain and theme, and every project gets the same result on every machine and in CI.

</details>
