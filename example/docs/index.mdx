## How it works

<Steps>

1. **Write** Markdown in a `docs/` folder and describe your site in `docs.yml`.

2. **Preview** with live reload:

   ```sh
   docker run --rm -p 4321:4321 -v "$PWD":/project ghcr.io/laidwin/kiln serve
   ```

3. **Publish** to GitHub Pages with a few lines of workflow YAML.

</Steps>
