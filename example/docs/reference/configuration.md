Every project has a `docs.yml` file at its root, next to the `docs/` folder. It is validated at startup: an unknown or mistyped option stops the build with an error pointing to the exact line.

```txt
Error: docs.yml is invalid:

  • [line 3] accent: must be a hex color (#rgb or #rrggbb), e.g. "#f76b15"
  • [line 5] unknown key "colour". Allowed keys: title, description, logo, …
```

## Full example

```yaml title="docs.yml"
title: My project
description: What my project does, in one sentence.
logo: docs/assets/logo.svg
accent: "#f76b15"
locale: en
base: /my-project
site: https://example.github.io
social:
  github: https://github.com/example/my-project
editLink: https://github.com/example/my-project/edit/main/
poweredBy: true
fonts:
  body: docs/assets/fonts/text.woff2
css: docs/assets/brand.css
nav:
  - { label: Guides, link: /guides/writing-content/ }
include:
  - { file: CHANGELOG.md, slug: changelog }
sidebar:
  - getting-started
  - label: Guides
    autogenerate:
      directory: guides
  - label: Changelog
    link: https://github.com/example/my-project/releases
```

## Options

| Key           | Required | Default       | Description |
| ------------- | :------: | ------------- | ----------- |
| `title`       | yes      | none         | Site title, shown in the header and browser tabs. |
| `description` | no       | none         | Site description, used by search engines. |
| `logo`        | no       | none         | Logo image, see [below](#logo). |
| `accent`      | no       | `#f76b15`     | Accent color, as a quoted hex value (`"#rgb"` or `"#rrggbb"`). |
| `theme`       | no       | Kiln palette  | Colors for light and dark modes, see [Customizing](/guides/customizing/#colors). |
| `locale`      | no       | `en`          | Interface language: `en` or `fr`. |
| `base`        | no       | `/`           | Base path the site is served from, e.g. `/my-project`. In the GitHub Pages workflow, defaults to `/<repo>`. |
| `site`        | no       | none         | Public URL of the site, used for canonical links and the sitemap. |
| `social`      | no       | none         | Links shown as icons in the header, see [below](#social). |
| `sidebar`     | no       | autogenerated | Custom navigation, see [below](#sidebar). |
| `editLink`    | no       | none         | Base URL for "Edit page" links, pointing to the project root in your repository. |
| `poweredBy`   | no       | `true`        | Shows a discreet "Built with Kiln" link at the bottom of every page. Set to `false` to hide it. |
| `fonts`       | no       | Inter, system mono | `.woff2` fonts for `body`, `heading` and `mono`, see [Customizing](/guides/customizing/#fonts). |
| `css`         | no       | none         | Stylesheet loaded after the theme, see [Customizing](/guides/customizing/#custom-css). |
| `nav`         | no       | none         | Header links, see [Customizing](/guides/customizing/#header-links). |
| `include`     | no       | none         | Markdown files from outside `docs/` to publish, see [below](#include). |
| `api`         | no       | none         | OpenAPI or Python API reference, see [below](#api). |

## `logo`

Either a path relative to `docs.yml`, or an object:

| Form | Example |
| ---- | ------- |
| Single image | `logo: docs/assets/logo.svg` |
| With options | `logo: { src: docs/assets/logo.svg, alt: My project, replacesTitle: true }` |
| Light and dark | `logo: { light: docs/assets/light.svg, dark: docs/assets/dark.svg }` |

## `social`

A map from icon to URL:

```yaml
social:
  github: https://github.com/example/my-project
  discord: https://discord.gg/example
```

Or a list, to set custom labels:

```yaml
social:
  - icon: github
    label: Source code
    href: https://github.com/example/my-project
```

Available icons: `github`, `gitlab`, `bitbucket`, `codeberg`, `forgejo`, `azureDevOps`, `discord`, `slack`, `microsoftTeams`, `mastodon`, `blueSky`, `x.com`, `twitter`, `linkedin`, `youtube`, `stackOverflow`, `npm`, `rss`, `email`, `telegram`, `matrix`, `zulip`, `discourse`, `reddit`.

## `sidebar`

Without `sidebar`, navigation mirrors the `docs/` folder. Each entry of a custom sidebar takes one of these forms:

| Form | Example |
| ---- | ------- |
| Page slug | `- getting-started` |
| Page with a custom label or badge | `- { slug: guides/intro, label: Introduction, badge: New }` |
| External or arbitrary link | `- { label: Changelog, link: https://… }` |
| Group of entries | `- { label: Guides, items: [guides/intro, guides/advanced] }` |
| Group generated from a folder | `- { label: Guides, autogenerate: { directory: guides } }` |

Groups accept `collapsed: true` to start folded.

## `include`

Publishes Markdown files that live outside `docs/`:

| Key | Required | Description |
| --- | -------- | ----------- |
| `file` | yes | Path to a `.md` file, relative to `docs.yml`. |
| `slug` | yes | Page path on the site, lowercase, without extension: `changelog`, `project/changelog`. |

The page appears in the sidebar group of its folder, and its edit link points to the file itself.

## `api`

Generates an API reference under `/api/`, from an OpenAPI description or from a Python package:

```yaml
api:
  openapi: docs/openapi.yaml
  server: https://api.example.com
```

```yaml
api:
  python: api.json
  exclude: [my_package.tests, my_package.internal]
```

| Key | Description |
| --- | ----------- |
| `openapi` | Path to an OpenAPI 3.0 or 3.1 description (YAML or JSON), relative to `docs.yml`. |
| `server` | Host used in the code samples when the description's server URL is relative, or to replace its host. |
| `python` | Path to the JSON file written by [griffe](https://mkdocstrings.github.io/griffe/), relative to `docs.yml`. |
| `exclude` | Python modules to leave out, with their submodules. |

Set `openapi`, `python`, or both: alone, a reference lives under `/api/`; together, the Python reference keeps `/api/` and the OpenAPI one moves to `/api/rest/`.

See [Adding an API reference](/guides/api-reference/) for how to generate the file.
